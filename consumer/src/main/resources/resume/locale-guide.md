# Locale Guide

## Shared rules

- Show dates consistently. Preserve month-level precision; never create a month from a year alone.
- Use `Present`, `至今`, or `現在` only for ongoing roles.
- Keep technical names in their conventional form: `Dynamics 365 Finance & Operations`, `X++`, `Spring Boot`, `Spring AI`, `LLM`.
- Put the most job-relevant evidence first. Recruiters should understand the candidate in 20–30 seconds.

## Chinese

- Default document title: `个人简历`.
- Preferred section labels: `职业摘要`, `核心能力`, `工作经历`, `项目经历`, `教育背景`, `专业资格`, `语言能力`, `作品与链接`.
- Use concise bullets and exact technical terms. Avoid slogans and exaggerated self-evaluation.
- Job titles from another language may include the original title in parentheses when the translation is ambiguous.

## English

- Default document title: `RESUME` for a general professional resume; use `CURRICULUM VITAE` only when the target market expects a CV.
- Preferred labels: `PROFILE`, `CORE SKILLS`, `EXPERIENCE`, `EDUCATION`, `SELECTED PROJECTS`, `PORTFOLIO`, `CERTIFICATIONS`, `LANGUAGES`.
- Use past tense for completed work and present tense for ongoing responsibilities.
- Start bullets with specific verbs. Add outcomes only when supported by evidence.

## Japanese

- Default experienced-hire document: `職務経歴書`.
- Preferred labels: `職務要約`, `活かせる経験・スキル`, `職務経歴`, `学歴`, `主要プロジェクト`, `個人開発・ポートフォリオ`, `資格・語学`, `補足`.
- Use the supplied katakana exactly. Do not invent a Japanese reading.
- Render `JLPT N2` as `JLPT N2`; do not convert it to `ビジネスレベル` or `流暢`.
- Use `フルリモート（応相談）` only when remote work is genuinely negotiable. Use `フルリモート可` only when the user confirms it is available.
- Preserve company names in a readable form and add the original name when it materially helps identification.

## Dates

- Chinese and English: `YYYY.MM - YYYY.MM`.
- Japanese: `YYYY.MM - YYYY.MM` followed by `現在` for an ongoing role.
- When the source has only years, render years only.

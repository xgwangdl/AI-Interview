# Resume Content Integrity

## Evidence hierarchy

Use the most specific source available:

1. Explicit statement in the source resume or portfolio.
2. Directly calculable fact such as an employment duration from exact dates.
3. Conservative paraphrase of a listed responsibility.
4. Clearly marked question for missing information.

Do not move a lower level into a stronger claim.

## Wording tests

Before using a strong word, verify the source supports it:

- `expert`, `精通`, `業務レベル`, `fluent`: the source must show sustained hands-on use or an explicit level.
- `led`, `managed`, `主导`, `リード`: the source must name people, scope, or project responsibility.
- `improved X%`, `reduced cost`, `shortened delivery`: the source must contain the metric.
- `architected`: distinguish solution design from implementation support.
- A certification name must include the exact issuer or specialization when known; otherwise keep the generic name.

## Missing information

Omit optional missing fields. If the resume cannot be delivered without a required personal field for the requested document type, ask one concise question. Do not use placeholders in the final file.

For Japanese standard `履歴書`, required personal fields commonly include the date, name, address, contact information, education/work chronology, and sometimes a photo. A `職務経歴書` can be produced from career evidence alone.

## Confidentiality

Use client and project names only when supplied. For public portfolio copy, anonymize with descriptions such as `a multinational manufacturing company` when the source does not authorize disclosure. Internal screenshots, source code, customer data, and architecture documents require explicit public-disclosure permission.

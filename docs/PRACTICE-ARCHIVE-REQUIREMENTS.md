## 1. 为什么要做（现状的问题）

系统已经能出题、模拟面试、评分、出报告，笔试与简历也齐了。但从产品上看有个洞：

- **报告只看单场**：`HistoryView` / `DashboardView` 里没有任何跨场次统计，用户拿到分数后没有"下一次"的落点；
- **练习整体过期**：`PracticeSessionService.cleanupExpired` 按 `retentionUntil` 连场次、回答、报告一起删，所以现在**存不下长期成长**；
- **知识没有被复用**：每道题的 5 个维度分是现成的，但从没被聚合过 —— 用户不知道"我到底哪一维最弱、有没有变好"。

一句话：**练了没有下文，也没有理由回来练第二次。**

## 2. 范围

### 2.1 本期做（一期，已完成）

1. **成绩趋势**：最近 N 场（默认 5）的整体分折线，标出日期与分数；
2. **维度平均**：5 个维度在窗口内的平均分，最弱的几条标出来；
3. **短板与建议**：低于 75 分的维度里取最低的 1-3 个，每个给一句可执行的改法；
4. **针对短板再练一场**：一键把岗位与弱项维度带到配置页，出题时多出能暴露这些问题的题；
5. **同一套数据在页面上自洽**：范围说明写明"只统计还没过期的练习"，不假装做了长期跟踪。

### 2.2 二期：分数长期保留（已完成）

| 编号 | 需求 | 验收要点 |
| --- | --- | --- |
| FR-9.10 | 成绩与录像分开保留 | 新增 `practice_score_archive`（V9）：**只存分数与维度**，不含转写与录像；场次 7 天到期被清理后档案仍在 |
| FR-9.11 | 回填历史 | 迁移里把已有评分一并回填，升级完不会"历史成绩反而没了" |
| FR-9.12 | 幂等写入 | 评分完成后记一笔；同一场次同一道题唯一（唯一索引 + 存在性检查），分析任务重试不会写重复分数 |
| FR-9.13 | 删除语义 | 用户主动删某场练习 → 该场成绩一起删；**到期自动清理 → 只删录像与练习，档案保留** |
| FR-9.14 | 一键清空档案 | `DELETE /api/v1/practice-archive`：只清长期统计，练习与录像按各自保留策略走 |
| FR-9.15 | 页面对齐 | 档案页的范围说明改为"统计长期保留的分数（不含录像与转写）" |

### 2.3 以后再说

- 自定义对比区间（近 30 天 / 全部）、按岗位分组对比、导出档案；
- 错题本（把具体某道题重练）——现在的粒度是"维度"，不是"题目"（分数表已按题存，具备条件）；
- 多人对比、招聘方视角。

## 3. 功能需求（FR-9）

| 编号 | 需求 | 验收要点 |
| --- | --- | --- |
| FR-9.1 | 成绩趋势 | 窗口内已完成且有评分的场次按**时间正序**返回；只有一场时画一个点并提示"再练一场就能看到趋势" |
| FR-9.2 | 维度平均 | 5 个维度（relevance / completeness / professionalism / starStructure / logic）在窗口内的平均，顺序稳定 |
| FR-9.3 | 短板判定 | 平均分 **< 75** 才算短板，最多 3 个，按分数升序；全都在 75 以上时不给短板，改为建议"提高难度" |
| FR-9.4 | 可执行建议 | 每个短板配一句可照做的话（"讲经历按 Situation → Task → Action → Result 走，尤其别漏 Result"），不是空泛的"继续加油" |
| FR-9.5 | 短板复练 | 「针对短板再练一场」带 `role` 与 `focus` 跳到 `/practice/setup`，配置页预填岗位并显示"本次重点考察：…"，可一键清除 |
| FR-9.6 | 出题倾向 | `focus` 只影响出题倾向（多出能暴露这些问题的题），**不改变题目总数、题型与难度**；无法识别的维度忽略 |
| FR-9.7 | 没评分的场次不入档 | "0 分"和"还没评分"是两回事：后者不进趋势、不参与平均 |
| FR-9.8 | 范围诚实 | 接口返回 `scopeNote` 说明统计范围（当前：只含还没过期的练习），页面原样显示 |
| FR-9.9 | 隔离 | 只能看自己的档案，未登录 401 |

## 4. 数据与接口

**不新增表、不新增迁移**：一期纯粹是聚合现有数据（`practice_sessions` + `practice_answers.evaluation_json`）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/v1/practice-archive?limit=5` | 返回 `{scopeNote, windowSize, totals, enoughForTrend, trend[], dimensions[], weakest[]}`；`limit` 限定 1-10 |

维度 key 与分数由后端给出，**中文标签与建议文案在前端**（`web/src/services/practiceArchive.js`）：
这样调整措辞不用重新部署后端，而 key → 中文的翻译只有一处；
反过来，出题提示里需要的中文标签由**后端**翻译（`SpringAiQuestionPlanProvider.focusLine`），
因为提示词不该依赖前端传中文。

## 5. 前端设计

- 位置：`/`（训练总览）原有的三张概览卡下面，新增"训练档案"一段，不新开页面 —— 用户打开系统第一眼就是它；
- 三栏：**最近得分**（SVG 折线，自己算坐标，不引图表库）／**维度平均**（条形，弱项琥珀色）／**下一步练什么**（短板 + 建议 + CTA）；
- 空状态（没有任何已评分场次）给明确引导，而不是空白区域；
- 折线数据只有 1 个点时：画点 + 文字说明，不画"一根线"。

## 6. 验收标准

| # | 验收项 | 通过判据 |

| A15 | 聚合正确 | 5 场递增数据 → 趋势按时间正序；维度平均与手算一致；短板取最低的 1-3 个 |

| A19 | 隔离与降级 | 未登录 401；档案接口失败时总览页其余部分照常显示（档案是增强项） |

# Light-Interview v0.2.0-beta.1

首个公开 Beta 版本，提供从岗位目标、模拟面试到报告复盘和专项重练的完整练习闭环。

## 在线体验

- Web Demo: <https://5aicv.cn>
- 无需安装即可查看界面。
- Demo 已启用 Let's Encrypt HTTPS，可直接使用麦克风和摄像头录制。

## 主要更新

- 支持简体中文、English、日本語界面，并可在个人设置中切换语言。
- AI 根据岗位、JD 和简历生成问题，支持追问、转写、结构化评分和视频时间点证据。
- 报告支持回答改写、示范回答、重录前后对比、错题本和每日训练计划。
- 提供 Java、Python、C++、JavaScript、Go 的网页 IDE 与 Docker 隔离判题能力。
- 支持求职目标、连续面试、周报、学习小组、作业、互评和简历优化。
- 增加个人资料、主题色、字号、账号安全和 AI 使用额度设置。
- 增加阿里云 2 核 2G 单机部署配置与 GHCR Docker 镜像发布流程。

## Docker 镜像

本版本发布后可从 GitHub Container Registry 获取：

```bash
docker pull ghcr.io/xgwangdl/light-interview-backend:0.2.0-beta.1
docker pull ghcr.io/xgwangdl/light-interview-web:0.2.0-beta.1
```

镜像同时提供 `sha-*` 标签，便于固定到具体提交。

## 验证状态

- 后端 Docker 镜像构建成功。
- 前端 Docker 镜像构建成功。
- 阿里云单机环境的 Web、Backend、PostgreSQL、Redis 容器均已达到健康状态。
- 域名注册、登录和受保护 API 已通过真实浏览器与 HTTP 请求验证。

## 已知限制

- 这是 Beta 预发行版，接口和行为仍可能调整。
- 公网 Demo 为 HTTP，语音与摄像头能力需要部署 HTTPS 后使用。
- 公网 Demo 默认关闭代码执行沙箱。
- 当前目标平台为 `linux/amd64`。

## 3. 缺陷明细

### BUG-001：前端 Vitest 无法启动，测试命令因 esbuild spawn EPERM 失败

- 所属模块：工程质量/自动化测试
- 严重程度：一般；优先级：P1
- 缺陷类型：测试基础设施
- 测试环境：Windows，本地 Node.js 25.8.1，web/node_modules 已存在。
- 前置条件：进入 `web` 执行 `npm test -- --reporter=dot`。
- 复现步骤：1. `cd C:\workspace\AI-Interview\AI-Interview\web`；2. `npm test -- --reporter=dot`。
- 预期结果：Vitest 加载配置并执行用例。
- 实际结果：配置加载阶段失败：`Error: spawn EPERM`，调用栈指向 `esbuild`。
- 复现频率：每次执行。
- 证据：命令输出见本报告记录；未生成测试报告。
- 初步原因：当前受限 Windows 运行环境阻止 esbuild 子进程启动，可能与权限/安全策略或 Node 版本兼容性有关。
- 建议：在受控开发机检查 Node LTS、esbuild 二进制权限与安全软件策略；在 CI 上执行同一命令确认是否为环境特有问题。
- 复测：未复测，未修改项目。

### BUG-002：Playwright 已声明依赖但浏览器执行文件缺失，E2E 无法启动

- 所属模块：自动化测试
- 严重程度：一般；优先级：P1
- 缺陷类型：测试环境配置
- 前置条件：使用项目 `web/node_modules/playwright` 启动 Chromium。
- 复现步骤：调用 `chromium.launch({headless:true})`。
- 预期结果：启动浏览器并访问本地页面。
- 实际结果：提示 `Executable doesn't exist ... chrome-headless-shell.exe`，要求运行 `npx playwright install`。
- 复现频率：每次新环境执行。
- 证据：Playwright 启动错误输出。
- 初步原因：package.json 只有依赖，没有安装浏览器二进制/缓存未纳入环境。
- 建议：在 CI 安装固定版本浏览器并缓存；提供明确的 E2E bootstrap 命令。
- 复测：未复测；本轮未擅自下载依赖。

### BUG-003：后端根路径 `/` 返回 404

- 所属模块：后端可用性/部署
- 严重程度：轻微；优先级：P2
- 缺陷类型：接口/部署体验

- 复现步骤：GET `http://localhost:8088/`。

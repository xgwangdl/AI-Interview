## 第二轮执行补充

使用演示账号 `smoke/123456` 运行：

```powershell
pwsh scripts/smoke-test.ps1 -BaseUrl http://localhost:8088 -Name smoke -Code 123456 -ExpectAnalysisReady -AnalysisTimeoutSeconds 45 -ReportOut reports/evidence/api/smoke-report.json
```

结果：核心 HTTP 链路 20 项检查中 16 项通过，分析 ready 相关 4 项失败；失败原因是上传的 17 字节占位媒体无法被 FFmpeg 解码。会话已自动删除。

Playwright Chromium 安装已尝试但因下载无输出超时停止，浏览器 E2E 仍阻塞。

## 无浏览器下载时的替代自动化

新增 `scripts/browser-smoke.cjs`，通过 CDP 连接本机已有 Chrome，覆盖登录页、注册页、空值校验和未登录路由重定向。当前机器的 Chrome 未能监听 `9222`，所以脚本未通过；不能把它当作已完成 UI E2E。

可执行的替代验证：

```powershell
pwsh scripts/smoke-test.ps1 -BaseUrl http://localhost:8088 -Name smoke -Code 123456 -ExpectAnalysisReady -ReportOut reports/evidence/api/smoke-report.json
```

该方案覆盖后端真实业务闭环和权限边界；SPA 页面则用 PowerShell HTTP 检查入口状态。要完成真实点击、录音权限和 DOM 断言，应在允许 Chrome CDP 或 Playwright 浏览器缓存的 CI/开发机执行 `node scripts/browser-smoke.cjs`。
